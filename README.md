# SmileySolutions Portfolio

A high-end, modern portfolio website for **Kim Kroll** - Full Stack Developer working remotely as a Digital Nomad.

## Live Demo

🌐 [smileysolutions](https://smileysolutions.netlify.app/)

## About

This portfolio showcases professional work and skills in full-stack web development. Built with a focus on performance, accessibility, and modern design aesthetics featuring smooth animations and a premium user experience.

## Tech Stack

| Category | Technologies |
|----------|-------------|
| **Framework** | Next.js 15 (App Router) |
| **Frontend** | React 19, TypeScript |
| **Styling** | TailwindCSS v4 |
| **Animations** | Framer Motion |
| **Icons** | React Icons |
| **Deployment** | Netlify / Vercel |

## Features

- **Responsive Design** - Mobile-first approach with Tailwind breakpoints (sm, md, lg, xl)
- **Premium Animations** - Text reveal effects, parallax backgrounds, staggered menu animations
- **SEO Optimized** - Meta tags, Open Graph, Twitter cards, JSON-LD structured data
- **Performance** - Optimized images with next/image, font preloading, minimal bundle size
- **Accessibility** - Semantic HTML, ARIA labels, keyboard navigation support
- **Modern UI** - Full-screen mobile menu, scroll progress bar, smooth scrolling

## Sections

1. **Hero** - Animated text reveal with parallax background
2. **Services** - Full Stack, Web Design, Deployment, Technologies
3. **Projects** - Featured work with live demos and source code links
4. **About** - Professional summary with skills and social links
5. **Contact** - Direct contact options with WhatsApp integration

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/krollkim/SmileySolutions.git

# Navigate to project directory
cd smileysolutions

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```
